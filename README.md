# 🎵 YouTube to MP3 Telegram Bot

Telegram-бот на **Python 3.12 + aiogram 3 + yt-dlp + FFmpeg**, который принимает ссылки на **отдельные видео** или **целые плейлисты** YouTube (включая YouTube Shorts и YouTube Music), конвертирует аудиодорожку в `.mp3` и отправляет пользователю аудиофайлы, **подписанные точным названием видеоролика** (как в имени файла `Названия_видео.mp3`, так и в ID3-тегах и подписи).

Проект полностью упакован в Docker и готов к деплою в **Coolify** через GitHub в пару кликов.

---

## ✨ Возможности

- **Одиночные видео и Shorts** — мгновенное извлечение лучшей аудиодорожки и конвертация в MP3.
- **Целые плейлисты YouTube** — поочерёдное скачивание и отправка всех треков плейлиста с отображением прогресса (`[1/25]`, `[2/25]` и т.д.) и возможностью остановить очередь командой `/cancel`.
- **Умное распознавание ссылок** — если отправить ссылку на ролик, который находится внутри плейлиста (`watch?v=...&list=...`), бот покажет кнопки выбора: **«🎵 Только это видео»** или **«📂 Весь плейлист»**.
- **Подпись по названию видео** — каждый отправляемый файл именуется строго по названию видео на YouTube (`<Название видео>.mp3`), содержит вшитые метаданные (Title, Artist/Channel) и обложку видео.
- **Автоочистка временных файлов** — каждый скачанный трек удаляется с сервера сразу после отправки в Telegram, поэтому диск сервера никогда не переполняется.

## 🚀 Деплой в Coolify через GitHub

1. Загрузите этот репозиторий в ваш GitHub.
2. В панели **Coolify** нажмите **+ New Resource** -> **Public / Private Repository (GitHub)**.
3. Выберите репозиторий и ветку (например, `main`).
4. В качестве **Build Pack** выберите:
   - **Dockerfile** (рекомендуется) или **Docker Compose**.
5. Перейдите во вкладку **Environment Variables** в Coolify и добавьте переменную:
   - `BOT_TOKEN` = `ваш_токен_от_BotFather`
   *(При необходимости добавьте опциональные переменные из `.env.example`, например `AUDIO_BITRATE=192` или `MAX_PLAYLIST_ITEMS=50`)*.
6. Нажмите **Deploy**. Coolify соберёт образ с `ffmpeg` и `yt-dlp`, запустит контейнер и будет автоматически перезапускать его при обновлениях в GitHub!

> **Примечание для Coolify:** Так как бот работает по протоколу Long Polling (сам опрашивает серверы Telegram), ему **не нужно** открывать внешние HTTP-порты или настраивать домен/SSL. В Dockerfile уже настроен внутренний `HEALTHCHECK`, который проверяет процесс бота.

## 💻 Локальный запуск

### Вариант 1: Через Docker Compose
```bash
cp .env.example .env
# Укажите ваш BOT_TOKEN внутри .env
docker compose up --build -d
```

### Вариант 2: Без Docker (Python 3.11+ и установленный FFmpeg)
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Укажите ваш BOT_TOKEN внутри .env
python -m bot.main
```

## ⚙️ Переменные окружения (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | *(обязательно)* | Токен Telegram-бота от `@BotFather` |
| `AUDIO_BITRATE` | `192` | Битрейт MP3 в кбит/с (`128`, `192`, `320`) |
| `MAX_PLAYLIST_ITEMS` | `50` | Максимальное число видео, скачиваемых из одного плейлиста за раз |
| `MAX_DURATION_SECONDS` | `7200` | Максимальная длительность одного видео в секундах (7200 = 2 часа) |
| `MAX_CONCURRENT_DOWNLOADS` | `2` | Максимальное количество одновременных конвертаций |
| `ALLOWED_USER_IDS` | *(пусто)* | Список Telegram ID через запятую (если пусто — бот доступен всем) |
| `COOKIES_FILE` | *(пусто)* | Путь к `cookies.txt` (Netscape), если дата-центр VPS блокируется YouTube |
| `PROXY_URL` | *(пусто)* | HTTP/SOCKS5 прокси для `yt-dlp` (при необходимости) |
